AYUDA
EN LA PRÁCTICA
Las herramientas contenidas en esta aplicación tienen el propósito de permitirle a los usuarios (estudiantes) adquirir el conocimiento de una forma más compleja y orientada hacia la infografía. Se trata de que el alumno pueda, por ejemplo, ver de una forma más práctica, el funcionamiento de una compuerta o de un sistema de numeración.
Estas herramientas complementan las explicaciones que se dan en las secciones de "Elementos Teóricos" y se pueden clasificar como:
  1. Generadores: Se utilizan para generar una información de salida a partir de una información de entrada dada por el usuario. La información generada pueden ser por ejemplo, listas de números, tablas booleanas, circuitos lógicos, etc.
  2. Convertidores: Se emplean para convertir por ejemplo, números de un sistema de numeración a otro distinto.
  3. Emuladores: Con estas herramientas se pueden emular compuertas lógicas y circuitos lógicos, permitiendo así a los estudiantes adquirir el conocimiento de una forma práctica.
La estructura e implementación de cada una de las herramientas presentes en la aplicación se deben a su función y propósito, por lo que no tienen siempre el mismo aspecto. Pero, es posible identificar ciertas regularidades en algunas herramientas.
La mayoría de las herramientas implementadas en la aplicación necesitan que el usuario introduzca cierta información en la página, la cual es procesada al presionar un bótón cuyo nombre varía en dependencia de la herramienta que se esté empleando. Luego de presionar este botón, el resultado, sea una generación, una conversión o una emulación, será mostrado. Además, cada herramienta brinda una explicación breve de como debe ser empleada. Tambíen se debe indicar, que algunas herramientas incluyen un teclado virtual con los símbolos y operadores necesarios para que los usuarios que no esten familiarizados con las herramientas lo puedan emplear cuando sea necesario introducir alguna expresión matemática o un número. Los símbolos y la estructura de cada teclado virtual dependen del tipo de herramienta.
