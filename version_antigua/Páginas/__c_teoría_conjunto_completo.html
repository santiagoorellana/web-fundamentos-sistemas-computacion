COMPUERTAS LÓGICAS
Conjunto de compuertas lógicas completo:
Un conjunto de compuertas lógicas es completo si con él se puede implementar cualquier función booleana.
A la derecha se pueden ver distintos conjuntos completos.
Conjuntos completos
Conjunto AND, OR y NOT.
Conjunto OR y NOT.
Conjunto AND y NOT.
Conjunto NAND.
Ejemplos de conjuntos completos:
A nan B = not A
(A nan B) nan (A nan B) = A and B
(A nan A) nan (B nan B) = A or B
Utilizando las compuertas NAN es posible implementar las operaciones básicas. Isquierda.
Igualmente, con las compuertas NOR se pueden implementar las compuertas básicas. Derecha.
A nor A = not A
(A nor B) nor (A nor B) = A and B
(A nor A) nor (B nor B) = A or B
